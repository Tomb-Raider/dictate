# Диктовка в буфер обмена

Команда в Терминале, как Handy: говоришь, текст сам попадает в буфер обмена. Распознаёт локально,
без интернета, моделью Whisper (large-v3-turbo) на Mac с M-чипом. Прав администратора не нужно,
всё ставится в домашнюю папку

Нужен Mac с M-чипом (M1-M4) и macOS 13 или новее

## Проверить, заработает ли

Ничего не устанавливает, занимает до минуты. По пунктам показывает чип, macOS, место на диске,
есть ли uv (менеджер Python) и открываются ли сервер пакетов, Hugging Face и GitHub. В конце итог

```bash
curl -fsSL https://raw.githubusercontent.com/Tomb-Raider/dictate/main/install.sh | zsh -s -- --check
```

Из скачанного ZIP то же самое

```bash
zsh ~/Downloads/dictate-main/install.sh --check
```

Если в итоге «не заработает», пункты с ✗ подскажут почему

## Установка

Два способа, результат одинаковый. Терминал открывается так: Cmd+Пробел, набрать «Терминал».
В обоих случаях при первой установке нужен интернет: установщик сам скачивает Python, пакеты
и модель, около 2 ГБ, 5-15 минут. Если uv на компьютере нет, установщик скачает его с astral.sh,
с GitHub или с сервера пакетов Python, смотря что открыто в сети

### Одной командой из Терминала

Вставить в Терминал и нажать Enter

```bash
curl -fsSL https://raw.githubusercontent.com/Tomb-Raider/dictate/main/install.sh | zsh
```

### Из скачанного ZIP

1. На странице [github.com/Tomb-Raider/dictate](https://github.com/Tomb-Raider/dictate) нажать Code → Download ZIP
2. Открыть скачанный `dictate-main.zip`, рядом появится папка `dictate-main`. Safari распаковывает сам
3. Вставить в Терминал и нажать Enter

```bash
zsh ~/Downloads/dictate-main/install.sh
```

Если папка лежит не в Загрузках: набрать в Терминале `zsh` и пробел, перетащить в окно файл
`install.sh` из этой папки, нажать Enter

### После установки

Открыть новое окно Терминала и набрать `dictate`. При первой записи macOS спросит доступ Терминала
к микрофону, разрешить. Программа живёт в `~/Диктовка`, скачанная папка больше не нужна.
Обновить: повторить установку любым способом, словарь при этом не трогается

## Как пользоваться

Enter и Ctrl+C работают, только когда активно окно Терминала

1. В Терминале набрать `dictate` и нажать Enter. Через несколько секунд появится
   «Enter: начать запись». Программа остаётся открытой, пока её не закрыть
2. Нажать Enter. Появится «● Пишу», можно говорить. Сказанное появляется в окне по фразам
3. Нажать Enter ещё раз. Запись остановится, весь отрезок уже в буфере обмена
4. Перейти в нужное окно и вставить Cmd+V
5. Следующий отрезок: вернуться в Терминал и снова Enter. Новый отрезок заменяет в буфере
   предыдущий, запускать `dictate` заново не нужно
6. Закончить совсем: Ctrl+C или закрыть окно Терминала

Вместо шага 1 можно дважды щёлкнуть по `~/Диктовка/Диктовка.command`

- Английский текст: `dictate en`
- Слова, которые путает: дописать в `~/Диктовка/словарь.txt`, через запятую. Он же правит написание (pixso станет Pixso)
- Все диктовки за день лежат в `~/Диктовка/История/`, если буфер успел перезаписаться
- Пишет со встроенного микрофона MacBook, даже если подключены AirPods, иначе они переходят в режим звонка

## Если что-то не так

- Пишет «Микрофон молчит»: Системные настройки → Конфиденциальность и безопасность → Микрофон →
  включить Терминал, потом перезапустить `dictate`
- Нужен Mac с M-чипом. На Intel установщик сам скажет и остановится
