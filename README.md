# Диктовка в буфер обмена

Команда в Терминале, как Handy: говоришь, текст сам попадает в буфер обмена. Распознаёт локально,
без интернета, моделью Whisper (large-v3-turbo) на Mac с M-чипом. Прав администратора не нужно,
всё ставится в домашнюю папку

## Установка

Открыть Терминал (Cmd+Пробел, набрать «Терминал»), вставить и нажать Enter

```bash
curl -fsSL https://raw.githubusercontent.com/Tomb-Raider/dictate/main/install.sh | zsh
```

Первый раз скачиваются Python, пакеты и модель, около 2 ГБ, 5-15 минут. Потом открыть новое окно
Терминала. При первой записи macOS спросит доступ Терминала к микрофону, разрешить.
Повторный запуск той же команды обновляет программу, словарь не трогает

## Как пользоваться

1. Терминал, набрать `dictate` и Enter. Или двойной клик по `~/Диктовка/Диктовка.command`
2. Enter, говорить, Enter
3. Cmd+V в любом окне. Пока говоришь, буфер уже наполняется по фразам
4. Следующая диктовка снова Enter. Выход Ctrl+C

- Английский текст: `dictate en`
- Слова, которые путает: дописать в `~/Диктовка/словарь.txt`, через запятую. Он же правит написание (pixso станет Pixso)
- Все диктовки за день лежат в `~/Диктовка/История/`, если буфер успел перезаписаться
- Пишет со встроенного микрофона MacBook, даже если подключены AirPods, иначе они переходят в режим звонка

## Если что-то не так

- Пишет «Микрофон молчит»: Системные настройки → Конфиденциальность и безопасность → Микрофон →
  включить Терминал, потом перезапустить `dictate`
- Установка упала на скачивании (закрытая сеть): модель можно перенести флешкой с другого Mac, папка
  `~/.cache/huggingface/hub/models--mlx-community--whisper-large-v3-turbo` (1,5 ГБ),
  положить в то же место и запустить установку снова
- GitHub с этого Mac не открывается: скачать папку на другом компьютере (Code → Download ZIP),
  перенести и запустить `zsh install.sh` из неё
- Нужен Mac с M-чипом. На Intel установщик сам скажет и остановится
